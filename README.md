Все три лабораторные — это развитие одного продукта: **Telegram-бота-ассистента для задач** [@task_hunter_bot](https://t.me/task_hunter_bot). Задача отправляется одним сообщением обычным текстом («Срочно отправить отчёт завтра в 15:00»), а бот сам ставит приоритет и дедлайн, напоминает о задаче и ведёт список дел.

В каждой папке `labN/bot` лежит полная рабочая версия бота на момент этой лабы: её можно запустить отдельно по инструкции из `README.md` внутри папки.

## Быстрый запуск последней версии

```bash
cd lab3/bot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env    # вставить BOT_TOKEN; для простого запуска MODE=polling
python bot.py
```

Автотесты (без интернета и токена): `python -m unittest -v` в любой папке `labN/bot`.

## Как делалось

Весь код написан LLM-агентом (Claude Code) по промптам на естественном языке; промпты и итерации описаны в отчётах.

Интересные решения:
- разбор русских дат без внешних библиотек: «до пятницы», «через 2 часа», «20 октября»; распознанное убирается из текста задачи;
- SQLite — главное хранилище, а Google Таблица — необязательное «зеркало»: бот работает, даже когда Google недоступен;
- отзывы и метрики собираются внутри бота, без отдельных форм.
