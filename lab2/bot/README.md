# Task Assistant Bot — лабораторная 2 (работа с данными)

Бот из лабораторной 1 плюс три источника данных:

1. **Google Таблица** (Google Sheets API) — каждая задача автоматически появляется в таблице и обновляется при изменении статуса или приоритета.
2. **Excel / CSV файлы** — `/export` присылает `.xlsx` со всеми задачами, а присланный боту `.xlsx` или `.csv` импортируется как список задач.
3. **SQLite** — основная база; поверх неё добавлены поиск, выборка за неделю и статистика.

## Файлы

| Файл | Что внутри |
|---|---|
| `bot.py` | бот: команды, кнопки, напоминания, импорт/экспорт |
| `task_parser.py` | разбор текста: приоритет, дедлайн, исполнитель |
| `database.py` | SQLite: задачи, поиск, статистика, миграция базы из лабы 1 |
| `sheets.py` | синхронизация с Google Таблицей |
| `excel_io.py` | экспорт в `.xlsx`, импорт из `.xlsx` / `.csv` |
| `test_bot.py` | автотесты (24 шт., без интернета) |
| `../examples/` | примеры файлов для импорта |

## Запуск

```bash
cd lab2/bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # вставь BOT_TOKEN
python bot.py
```

Без Google-настроек бот запускается и работает, просто без синхронизации с таблицей.

## Подключение Google Таблицы

1. [Google Cloud Console](https://console.cloud.google.com/) → создай проект → **APIs & Services → Library** → включи **Google Sheets API**.
2. **IAM & Admin → Service Accounts → Create service account** → открой его → **Keys → Add key → JSON**. Скачанный файл положи рядом с `bot.py` как `credentials.json` (он в `.gitignore`, в git не попадёт).
3. Создай обычную Google Таблицу в своём аккаунте. Нажми «Поделиться» и добавь email сервисного аккаунта (вида `...@...iam.gserviceaccount.com`) с правом **Редактор**.
4. Скопируй ID из ссылки `https://docs.google.com/spreadsheets/d/<ID>/edit` в `GOOGLE_SHEET_ID` в `.env`.
5. Перезапусти бота: в логе появится `Google Sheets sync enabled`.

## Новые команды

| Команда | Что делает |
|---|---|
| `/find слово` | поиск по тексту задачи и исполнителю (без учёта регистра) |
| `/week` | задачи, созданные за последние 7 дней |
| `/stats` | сколько задач в работе, выполнено, просрочено, по приоритетам |
| `/export` | присылает `tasks_ГГГГ-ММ-ДД.xlsx` |
| 📎 файл | импорт задач из `.xlsx` / `.csv` (в группе — с подписью `/import`) |
| `/sheet` | ссылка на Google Таблицу |
| `/sync` | перезаписать Google Таблицу всеми задачами из базы |

Команды лабы 1 (`/list`, `/today`, `/done`, `/del`, `/prio`, `/digest`, `/task`, `/help`) работают как раньше.

## Формат файла для импорта

Первая строка — заголовки. Обязательна колонка с задачей, остальные по желанию:

| задача | приоритет | дедлайн |
|---|---|---|
| Подготовить презентацию | высокий | 20.10.2026 10:00 |
| Записать видео-демо | средний | 19.10.2026 |
| Обновить README | низкий | |

Названия колонок: `задача`/`task`/`text`, `приоритет`/`priority`, `дедлайн`/`due`/`срок`. CSV можно в UTF-8 или Windows-1251, с разделителем `,` или `;` (как сохраняет русский Excel). Максимум 200 строк и 2 МБ.

## Обработка ошибок

- Google недоступен или нет прав → бот пишет ошибку в лог и продолжает работать.
- Файл не `.xlsx`/`.csv`, битый, пустой, без колонки «задача», больше 200 строк → понятное сообщение пользователю.
- `/done abc`, `/done 999`, `/prio 3 оч` → подсказка с правильным форматом.
