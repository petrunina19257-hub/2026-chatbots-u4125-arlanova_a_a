## 1. Описание деплоя

### Какой способ выбран

**Вариант 1: локальный запуск + ngrok в режиме webhook.**

```
Пользователь ──► Telegram ──HTTPS──► https://xxx.ngrok-free.app/webhook
                                          │  (туннель ngrok)
                                          ▼
                                 localhost:8000  ←  python bot.py (MODE=webhook)
                                          │
                                          ▼
                                  SQLite · bot.log · Google Таблица
```

### Почему именно этот

- Бесплатно и без привязки карты.
- Бот работает на моём компьютере, рядом лежат база, логи и ключ Google. Исправление после отзыва попадает к пользователям за секунды: остановить → поправить → запустить.
- Для тестовой недели с 3–5 пользователями этого достаточно. Минус — компьютер должен быть включён; на время теста помогает `caffeinate`.
- Запасной вариант для постоянной работы уже готов: `Dockerfile` и `docker-compose.yml` (`MODE=polling`, база в volume).

## 2. Процесс деплоя

### Подготовка кода (что изменено по сравнению с лабой 2)

| Требование из задания | Как сделано |
|---|---|
| Токен в переменных окружения | `BOT_TOKEN` и все настройки в `.env`, в git только `.env.example` |
| `.gitignore` | `.env`, `credentials.json`, `*.db`, `*.log`, `__pycache__/`, `.venv/` |
| `requirements.txt` | добавлен extra `[webhooks]` (веб-сервер tornado для приёма webhook) |
| Логирование | в консоль и в `bot.log` с ротацией 5 × 1 МБ |
| Обработка ошибок | глобальный error handler + проверка настроек при старте (`WEBHOOK_URL` должен быть `https://`) |
| Безопасность webhook | `WEBHOOK_SECRET`: Telegram присылает его в заголовке `X-Telegram-Bot-Api-Secret-Token`, запросы без него отклоняются |

Новое для работы с пользователями:

- `/feedback` — оценка ⭐1–5 кнопками, затем текст отзыва одним сообщением (или `/skip`). Оценка и текст сохраняются **одной записью** и сразу приходят администратору в Telegram.
- Статистика использования: обработчик в `group=-1` видит каждое обновление раньше остальных и пишет в таблицу `events`, какое действие сделал пользователь.
- `/admin` — пользователи всего и за 24 часа, задачи, популярные действия, средняя оценка; `/feedbacks` — последние отзывы.

### Пошаговая инструкция

1. Установить ngrok и привязать аккаунт:

   ```bash
   brew install ngrok
   ngrok config add-authtoken <NGROK_TOKEN>
   ```

2. Установить зависимости и создать `.env`:

   ```bash
   cd lab3/bot
   python3 -m venv .venv && source .venv/bin/activate
   pip install -r requirements.txt
   cp .env.example .env
   ```

3. Терминал 1 — туннель (с бесплатным постоянным доменом адрес не меняется):

   ```bash
   ngrok http --url=<домен>.ngrok-free.app 8000
   ```

4. В `.env`: `MODE=webhook`, `WEBHOOK_URL=https://<домен>.ngrok-free.app`, `PORT=8000`, `WEBHOOK_SECRET=<случайная строка>`.
5. Терминал 2 — бот (`caffeinate`, чтобы Mac не уснул):

   ```bash
   caffeinate -i python bot.py
   ```

   `run_webhook` сам вызывает `setWebhook`, вручную открывать ссылку из задания не нужно.

6. Проверка: `https://api.telegram.org/bot<TOKEN>/getWebhookInfo` → `url` совпадает, `pending_update_count: 0`; входящие запросы видны в панели ngrok `http://127.0.0.1:4040`.
7. Отправить боту `/admin` → получить свой ID → вписать в `ADMIN_IDS` → перезапустить.

|---|---|---|---|

Команды для проверки:

```bash

grep -c ERROR bot.log
```

### С какими проблемами столкнулись и как решили

| Проблема | Решение |
|---|---|
| В задании webhook ставится вручную через браузер, но адрес ngrok меняется при каждом перезапуске | `run_webhook(webhook_url=...)` регистрирует webhook сам при каждом старте; плюс бесплатный постоянный домен ngrok |
| Любой, кто узнает адрес ngrok, может слать на него поддельные обновления | `secret_token` в `run_webhook` |
| Для webhook нужен веб-сервер, которого не было в зависимостях | `python-telegram-bot[webhooks]` (tornado) |
| Сначала оценка и текст отзыва сохранялись двумя разными записями, статистика отзывов удваивалась | После оценки номер записи запоминается в `user_data`, следующее сообщение дописывается в неё |
| Если пользователь поставил оценку, а потом передумал писать отзыв, его следующая задача сохранилась бы как отзыв | Команда `/skip` и подсказка о ней в сообщении |
