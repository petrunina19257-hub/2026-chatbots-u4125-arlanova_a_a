# Лабораторная работа 1. Создание первого Telegram-бота без программирования

**Бот:** [@task_hunter_bot](https://t.me/task_hunter_bot)

**Код:** две версии одного бота:
- [`apps-script/Code.gs`](apps-script/Code.gs) — **рабочая версия** на Google Apps Script, ей пользуюсь я и коллеги;
- [`bot/`](bot/) — расширенная версия на Python (python-telegram-bot), как в шаблоне задания.

## 1. Описание задачи

Выбран вариант 3 — **бот-ассистент для задач**.

### Какую проблему решает бот

Задачи приходят со всех сторон: в рабочих чатах, на созвонах, в голове по дороге. Если их не записать сразу, они теряются. А если записывать в отдельный планировщик, нужно переключаться между приложениями.

Бот позволяет записать задачу, не выходя из Telegram: одно сообщение `/task текст` — и задача попадает строкой в Google Таблицу. Работает и в личке с ботом, и в общем чате, поэтому коллеги могут поставить задачу прямо из рабочего чата.

### Почему выбрана эта задача

Задачи — то, с чем я сталкиваюсь каждый день, а Telegram всегда под рукой. Хотелось сделать инструмент, которым правда пользуются, а не учебный пример ради сдачи. Google Таблица выбрана как хранилище, потому что её удобно открыть с компьютера, отфильтровать и отметить выполненное, а доступ к ней можно дать коллегам.

### Две версии

| | Apps Script (рабочая) | Python (расширенная) |
|---|---|---|
| Где работает | в облаке Google, по триггеру, без своего компьютера | на компьютере или сервере (`python bot.py`) |
| Как добавить задачу | `/task текст`, `/task@бот текст`, `/ task текст` | любое сообщение в личке; в группе `/task`, упоминание или ответ боту |
| Где хранит | Google Таблица | SQLite (+ Google Таблица и Excel в лабе 2) |
| Приоритеты и дедлайны | нет | распознаются из текста: «срочно», «завтра в 15:00», «до пятницы» |
| Список и статусы | в таблице, статус меняется вручную | `/list`, `/today`, `/done`, `/prio`, `/del` |
| Напоминания | нет | за час до дедлайна + утренний дайджест |
| Проверка | используется с лета 2026 | 16 автотестов + прогон всех команд на тестовых сообщениях Telegram |

Удобнее и проще в поддержке версия на Apps Script, поэтому в работе используется она. Версия на Python показывает, каким бот может стать дальше.

## 3. Стек технологий

### Версия на Apps Script

| Технология | Зачем | Почему она |
|---|---|---|
| Google Apps Script | среда выполнения бота | бесплатно, работает в облаке Google, не нужен сервер и включённый компьютер |
| Триггер по времени | регулярный запуск `pollTelegram` | заменяет постоянно работающий процесс |
| Telegram Bot API `getUpdates` + `UrlFetchApp` | получение сообщений | не нужен публичный адрес для webhook |
| `PropertiesService` | хранение `last_update_id` | сообщения не записываются повторно |
| `SpreadsheetApp` | запись задач в Google Таблицу | таблица — и база, и интерфейс для просмотра задач |

### Версия на Python

| Библиотека | Зачем | Почему она |
|---|---|---|
| Python 3.9+ | язык | стандарт для Telegram-ботов, есть на macOS из коробки |
| [python-telegram-bot](https://python-telegram-bot.org/) 21.10 `[job-queue]` | работа с Telegram API, команды, inline-кнопки | рекомендована в задании; асинхронная; встроенный **JobQueue** (на APScheduler) — для напоминаний и дайджеста не нужен отдельный планировщик |
| sqlite3 (встроена в Python) | хранение задач | не нужен сервер БД, вся база в одном файле `tasks.db`; в отличие от JSON, можно сортировать и фильтровать прямо SQL-запросом |
| python-dotenv | чтение `.env` | токен не попадает в код и в git |
| zoneinfo (встроена) | часовой пояс | дедлайны считаются по Москве, в базе время хранится в UTC |
| unittest (встроен) | автотесты | 16 тестов на разбор дат, приоритеты, базу и сборку бота — без интернета |

## 5. Трудности и решения

### Версия на Apps Script

| Что нужно было учесть | Как решено |
|---|---|
| Apps Script не может постоянно держать соединение с Telegram | Функция запускается по триггеру и забирает новые сообщения через `getUpdates` |
| Без подтверждения Telegram отдаёт одни и те же сообщения снова, и задачи задваивались бы | Номер последнего `update_id` хранится в `PropertiesService` и передаётся как `offset` |
| В группе Telegram дописывает имя бота: `/task@task_hunter_bot`, а с телефона иногда получается `/ task` | Одно регулярное выражение `^\/\s*task(?:@\w+)?\s+` ловит все варианты |
| Если что-то пошло не так с очередью сообщений | Функция `resetTelegramOffset` сбрасывает сохранённый номер |

### Версия на Python

| Русские даты пишут по-разному: «до пятницы», «в пятницу», «к пятнице» | Регулярные выражения по основе слова (`пятниц\w*`), «послезавтра» проверяется раньше «завтра», потому что содержит его внутри |
| «До пятницы», написанное в пятницу — это сегодня или через неделю? | Решили, что это следующая пятница: так дедлайн не окажется в прошлом |
| Дата без года, которая уже прошла («до 01.02» в октябре) | Переносим на следующий год |
| Время в базе: сравнивать даты разных часовых поясов строками нельзя | В базе всё хранится в UTC в формате `YYYY-MM-DD HH:MM:SS` — такие строки правильно сравниваются прямо в SQL |
| Пользователь пишет в задаче `<` или `<b>`, а сообщения отправляются в HTML-разметке | Весь пользовательский текст экранируется через `html.escape` |
| Нет реального токена при разработке | Автотесты и офлайн-прогон: в настоящий `Application` подавались поддельные сообщения Telegram, а все запросы к API перехватывались. Так проверены все команды, кнопки и группы ещё до запуска |

## 6. Выводы

**Что получилось хорошо.** Бот на Apps Script работает в облаке Google с лета без единого сервера и без включённого компьютера, им пользуются в рабочем чате. Задача записывается одной командой, не выходя из Telegram. Версия на Python показала, что тот же бот можно развить до полноценного ассистента: понимание дат на русском, приоритеты, напоминания. Разбор текста там покрыт тестами, поэтому LLM могла смело его менять.

**Что можно улучшить.** В версии на Apps Script бот не отвечает, что задача записана, и задача появляется в таблице с задержкой до минуты. Статус меняется только вручную в таблице. Всё это уже решено в версии на Python: ответ с номером задачи, `/done`, приоритеты, напоминания. Следующий шаг — перенести эти функции в Apps Script или запустить версию на Python на сервере.

**Чему научились.** Для простой задачи не всегда нужен сервер: Apps Script с триггером закрывает её бесплатно. Хороший промпт описывает не только «что сделать», но и крайние случаи («что если сообщение придёт дважды», «что если дата уже прошла») и как проверить результат.
