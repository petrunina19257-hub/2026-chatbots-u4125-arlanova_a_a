# Task Assistant Bot — лабораторная 1

Telegram-бот, который принимает задачи обычным текстом, сам расставляет приоритеты и дедлайны, напоминает о них и присылает утренний дайджест. Данные хранятся в SQLite (`tasks.db`).

## Файлы

| Файл | Что внутри |
|---|---|
| `bot.py` | сам бот: команды, кнопки, напоминания |
| `task_parser.py` | разбор текста: приоритет, дедлайн, исполнитель |
| `database.py` | работа с базой SQLite |
| `test_bot.py` | автотесты |
| `requirements.txt` | зависимости |
| `.env.example` | пример настроек |

## Запуск

Нужен Python 3.9 или новее.

```bash
cd lab1/bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # и вставь в .env токен от @BotFather
python bot.py
```

Проверка без Telegram: `python -m unittest -v`

## Как пользоваться

Напиши боту в личку:

```text
Срочно отправить отчёт завтра 15:00
Купить подарок до пятницы
Позвонить в банк через 2 часа
Не срочно разобрать почту
```

| Команда | Что делает |
|---|---|
| `/list` | открытые задачи, сначала срочные |
| `/today` | задачи на сегодня и просроченные |
| `/done 5` | отметить задачу №5 выполненной |
| `/del 5` | удалить задачу |
| `/prio 5 высокий` | сменить приоритет |
| `/digest on\|off` | утренний дайджест (по умолчанию в 09:00) |
| `/task текст` | добавить задачу (нужно в группах) |
| `/help` | справка |

Приоритет: «срочно», «важно», `!!` → 🔴 высокий; «не срочно», `#потом` → 🟢 низкий; иначе 🟡 средний.

Дедлайн: сегодня, завтра, послезавтра, дни недели, `20.10`, `20 октября`, `18:30`, через N минут/часов/дней/недель.

Напоминание приходит за час до дедлайна (если указано время) или в 10:00 в день дедлайна. Под ним кнопки «✅ Готово» и «⏰ +1 час».
